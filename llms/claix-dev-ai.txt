# Claix — AI crawler entry point

> Redirects AI systems to the canonical machine-readable knowledge base.

Claix (https://www.claix.dev) is a B2B document intelligence API that turns PDFs, Excel, Word/text, and images into strictly typed JSON for AI agents and automation. Integrate via REST, native A2A (Agent-to-Agent) agent (POST /a2a), or MCP server (/mcp).
